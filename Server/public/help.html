Wachtwoord vergeten? Zo herstel je het.

Je hoeft niets van programmeren te kennen om dit te doen.

Wanneer gebruik je dit?

  • Je bent je wachtwoord vergeten en kan niet meer inloggen
  • Er is geen enkele andere admin meer die je kan helpen
  • Je wil het wachtwoord van iemand anders resetten (bv. een collega die vastzit)

Wat heb je nodig?

Je moet fysiek bij de server zelf kunnen — dit werkt niet vanaf je eigen laptop of telefoon thuis, enkel rechtstreeks op de machine waar de applicatie op draait (of via een verbinding die daar rechtstreeks toegang toe geeft, zoals Remote Desktop naar die server). Dit is een bewuste beveiliging: zo kan niemand van buitenaf via het internet ooit een wachtwoord resetten.

Stap voor stap

  1. Zorg dat de applicatie draait. Vraag dit na bij wie de applicatie normaal opstart, of check of collega's momenteel nog kunnen inloggen — als zij wel kunnen inloggen, draait de server.
  2. Open een internetbrowser op de server zelf. Chrome, Edge, Firefox — maakt niet uit welke.
  3. Ga naar deze specifieke pagina:
    http://localhost:3000/recovery
  4. Vul het formulier in:
    VeldWat je invult
    EmailHet email-adres van het account waarvan je het wachtwoord wil wijzigen
    Nieuw wachtwoordEen nieuw wachtwoord naar keuze, minstens 8 karakters
    Bevestig wachtwoordHetzelfde wachtwoord, nog eens ingeven ter controle
  5. Klik op "Wachtwoord wijzigen." Bij succes zie je een groen bericht.
  6. Log in met je nieuwe wachtwoord op de gewone inlogpagina van de app.

Als er iets misgaat

Ik zie een foutmelding zoals "Forbidden" of "403"
Je probeert deze pagina te openen vanaf een ander toestel dan de server zelf. Dit werkt bewust enkel wanneer je op de server zelf surft naar deze pagina.

Ik zie "kon geen verbinding maken met de server"
De applicatie draait waarschijnlijk niet. Iemand moet deze eerst opstarten.

"Geen gebruiker gevonden met dit email-adres"
Je hebt het email-adres verkeerd getypt, of dat account bestaat niet.

Wat gebeurt er eigenlijk?

Het nieuwe wachtwoord wordt veilig versleuteld opgeslagen — niemand kan het originele wachtwoord ooit terug uitlezen. Er verandert verder niets aan je andere gegevens: klanten, sites, racks blijven gewoon staan zoals ze waren.
